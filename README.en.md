# sr-conf-ru

Routing configurations for the popular Shadowrocket proxy/VPN client, developed specifically for Apple OS.

DirectRU_D - routes all traffic through the VPN/proxy, except for Russian resources and Apple services.

DirectRU_S - a separate version that clearly specifies the servers used. It assumes you have VPN/proxy configurations named NL AWG 2.0 and WARP AWG 2.0. Among the advantages: YouTube traffic is routed through Cloudflare's Russian servers, removing ads from the app.
