# sr-conf-ru

Routing configurations for the popular Proxy/VPN client [Shadowrocket](https://apps.apple.com/us/app/shadowrocket/id932747118), developed specifically for Apple operating systems.
#
The configurations are divided into two types:

•	default — the Proxy/VPN configuration used is the one the user has selected on the main screen.

•	select — NL AWG 2.0 and WARP AWG 2.0 are used as Proxy/VPN configurations for certain resources (this option was created primarily for personal use).
