# sr-conf-ru

Конфигурации маршрутизации для популярного Proxy/VPN клиента Shadowrocket, разработанного специально для ОС от Apple

DirectRU_D - пускает весь трафик через VPN/Proxy, за исключением российских ресурсов, и сервисов Apple

DirectRU_S - отдельная версия, в которой чётко прописаны используемые сервера, подразумевает что у вас есть конфигурации VPN/Proxy с названиями NL AWG 2.0 и WARP AWG 2.0. Среди преимуществ: трафик YouTube идёт через российские сервера Cloudflare, что убирает рекламу из приложения.
